# Echo-Sight

## Overview

Echo-Sight is an Android application designed to assist visually impaired users by providing real-time obstacle awareness using on-device computer vision. The system delivers proximity and directional feedback through haptic signals and optional audio cues, enabling hands-free and voice-controlled operation.

---

## Tech Stack

* **Platform:** Android
* **Language:** Java
* **Camera:** CameraX
* **Machine Learning:** TensorFlow Lite (Object Detection)
* **Feedback:** Android Vibrator API, TextToSpeech
* **Voice Control:** Android SpeechRecognizer

---

## Repository Structure

The project follows a modular architecture with separate components for camera handling, object detection, proximity logic, feedback generation, and voice control to enable parallel development.
